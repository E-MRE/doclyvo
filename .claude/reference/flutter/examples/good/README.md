# Good Examples

This directory contains annotated code snippets that demonstrate correct patterns for this repository.

## How to Use

Each file should be named after the pattern it illustrates, e.g.:
- `correct_cubit_safeCall.dart`
- `correct_state_definition.dart`
- `correct_screen_mixin_pattern.dart`
- `correct_skeleton_loading.dart`
- `correct_model_definition.dart`

## When to Add Examples

Add an example here when:
- A pattern is subtle enough that a checklist rule alone is insufficient
- The same mistake has been repeated 2+ times in code review
- There is a nuanced "correct" way that differs from generic Flutter tutorials

## Format

Each example file should include a header comment block:

```dart
// PATTERN: <name>
// RULE: <which rule or skill file this demonstrates>
// WHY: <one sentence explaining why this is the correct approach>
```
